# 儿童习惯养成工具

一款面向家庭场景的轻量化习惯养成工具。通过「明确任务 → 每日打卡 → 即时正反馈 → 累计奖励 → 内驱力形成」的闭环设计，帮助孩子（及其他家庭成员）养成好习惯。

纯原生 HTML + CSS + JavaScript 单文件实现，**零外部依赖、双击即用、数据本地持久化**，无需安装任何环境，不联网第三方，隐私安全有保障。

## 功能一览

### 成员体系
- 支持创建任意数量的家庭成员（孩子、家长等），各成员数据完全独立
- 一键切换成员账户，每人有自己的习惯、积分、奖励、徽章与打卡记录
- 成员头像：内置 emoji 头像，也支持上传自定义图片（任意大小自动压缩为 768px 高清，不限制原图大小）
- **点击头像全屏预览**：照片等比缩放尽量铺满屏幕，点击任意处关闭
- 成员专属主题色，切换成员时界面色调同步变化

### 习惯管理
- 每个成员独立维护习惯列表，支持每日 / 每周固定 / 一次性三种频率
- 习惯可设定积分值（-20 ~ 10），正值 = 完成得分，负值 = 惩罚任务（未完成扣分，扣到 0 为止）
- **每日多次打卡**：可设置「每日目标次数」（如每天喝水 3 次），每次打卡得分，− / ＋ 按钮支持连续打卡与连续撤销
- **累计目标次数**：跨天累计打卡总数（如刷完一套牛津树 L1+ 全部 36 本），显示「📚 累计 18/36 次」进度，刷完自动庆祝
- **目标天数**：100 天挑战等长期目标，每天显示「第 5/100 天」进度
- **前置任务链**：可设置习惯的前置依赖（如 先复习 → 再背诵 → 抄生字 → 做题），未完成前置时锁定并提示
- **级联取消保护**：取消已打卡的前置任务时，自动弹窗提示并级联取消下游任务，防止数据矛盾
- 内置任务模板库（学习、生活、运动等），可一键下发给指定成员

### 打卡与激励
- 一键打卡，即时正反馈（动画 / 音效 / 鼓励语）
- 儿童模式附语音播报，低龄儿童无需识字即可独立操作
- 积分累计 → 兑换管理员预设奖励（实物、游乐时间、零花钱等）→ 管理员审批发放
- 连续打卡解锁成就徽章，增强荣誉感
- 每日自动结算昨日未完成的惩罚任务（自动扣分，扣到 0 为止）

### 管理端
- 管理设置受口令保护（默认 `1234`），可修改口令，口令仅当前会话有效
- 任务管理：按成员分组增删改习惯
- 奖励审批流程（成员申请 → 管理员审批 → 发放 / 驳回）
- 数据备份导出 / 导入恢复（JSON 格式）
- 存储兼容性检测：隐私模式或禁用存储时自动降级为内存存储并提示

### 界面模式
| 模式 | 适用人群 | 特点 |
|------|---------|------|
| 儿童模式 | 低龄儿童（幼儿园） | 大图标、大按钮、语音播报、贴纸感 |
| 少年模式 | 已识字儿童（小学） | 文字 + 图标结合、动画鼓励 |
| 简洁模式 | 成年人 / 自我管理 | 纯文字紧凑界面、信息密度高 |

## 快速开始

### 使用方式
1. 下载本仓库中的 `index.html` 文件
2. 双击用浏览器打开即可使用
3. 所有数据自动保存在浏览器本地存储中，无需联网

> 也可将 `index.html` 部署到任意静态文件服务器或 GitHub Pages 等，通过链接访问。

### 数据安全
- 数据存储在浏览器 localStorage 中，清除浏览器数据会导致丢失
- 建议定期使用「管理设置 → 数据与存储 → 导出备份」功能导出 JSON 备份
- 更换设备或重装系统时，可通过「导入恢复」功能从备份文件恢复全部数据
