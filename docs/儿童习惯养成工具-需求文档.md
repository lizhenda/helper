# 儿童习惯养成工具 — 需求文档

## 一、产品概述

### 1.1 项目背景
设计一款**家庭场景**的通用儿童习惯养成工具。首版以一个 8 岁女童（小学二年级上）和一个 6 岁男童（幼儿园大班）作为示例用户，但工具本身**不限定用户数量与身份**，可容纳任意数量的家庭成员（孩子、家长等），每个成员独立管理自己的习惯与成长数据。

### 1.2 产品定位
工具的核心不是"记录打卡"，而是**通过正向激励帮助成员养成好习惯**。围绕"明确任务 → 每日完成 → 即时正反馈 → 累计奖励 → 内驱力形成"的闭环设计。默认面向儿童习惯养成场景，同时保持通用性以支持其他家庭成员的自我管理需求。

### 1.3 使用角色
| 角色 | 说明 | 主要动作 |
|------|------|---------|
| 成员端（主力） | 每个成员独立使用自己的账户 | 查看任务、完成打卡、兑换奖励 |
| 管理端（家长） | 家长/管理员统一管理 | 管理成员、创建/调整任务、审核打卡、审批奖励、查看数据 |

## 二、技术形态

| 项目 | 方案 |
|------|------|
| 部署方式 | 网页版在线工具，通过浏览器访问 |
| 前端 | 原生 HTML + CSS + JS（轻量、简洁），延续白底+淡蓝主色、简约线条图标、毛玻璃弹窗的偏好 |
| 后端 | 极简本地/私有服务，用于多设备数据同步与保存 |
| 数据存储 | 服务端持久化存储，支持多设备同步 |
| 成员模式 | 多成员账户体系，每个成员独立数据，支持一键切换 |

## 三、核心功能需求

### 3.1 成员与角色
- **成员管理**：支持创建、编辑、停用、删除成员账户，不限数量；成员可为孩子、家长等任意角色
- 每个成员独立拥有自己的习惯、积分、奖励、徽章与打卡记录，互不干扰
- 成员头像：默认使用 emoji 头像（内置可选），也可**上传本地图片**作为自定义头像（自动压缩为 **768px** 高清 base64 存储——手机全屏查看几乎 1:1 不模糊，可随时清除恢复 emoji）；**不限制原图大小**：超过 5MB 的大图不再拒绝，自动压缩处理；超大尺寸（单边 > 4096px）先分步降采样再压缩，兼容移动端
- **点击头像全屏预览**：打卡页用户 chip 头像与「我的」页大头像均可点击，弹出**全屏查看器**：深色背景铺满屏幕，照片等比缩放尽量铺满（`100vw×100vh + object-fit:contain`，短边撑满不变形）；emoji 头像以超大字号（`min(55vw, 55vh, 480px)`）居中展示；底部显示成员名，右上角 × / 点击任意处关闭；不提供任何编辑功能，成员资料修改统一在管理端「成员管理 → 编辑」进行
- 顶部/侧边提供一键切换成员账户
- 管理端操作（管理成员、增删改任务、审批奖励）需简单口令保护，避免孩子误操作

### 3.2 习惯（任务）管理
- 每个成员独立维护自己的习惯列表
- 习惯支持按**频率**配置：每日执行 / 每周固定几天 / 一次性任务 / 艾宾浩斯复习（记忆类任务专属，详见下方）
- 每个习惯可设定**积分值**（按难度区分，如"整理书包 +1 分"、"阅读 20 分钟 +2 分"）
- 习惯可设置**每日目标次数**（`targetTimes`，默认 1）：适合每天需多次完成的任务（如"多喝水 3 次"）；
  - 设置后每天需打卡多次，**每次打卡得分**（积分按次计算），打卡满次数才算「完成」
  - 打卡页右侧提供 − / ＋ 两个圆钮，可连续打卡、连续撤销（达到上限后 ＋ 禁用，清零后 − 禁用）
  - 未满次数时显示进度条（如「2/3 次」），完成时显示「✅ 已完成 N 次」
  - 惩罚任务（负分）不支持多次打卡，固定为每日 1 次（编辑器联动禁用）
- 习惯可设置**累计目标次数**（`totalTargetTimes`，选填）：跨天累计打卡总数目标，适配「刷完一套分级读物」类任务（如牛津树 L1+ 全套 36 本，每级建一个任务）；
  - 打卡页显示「📚 累计 18/36 次」进度条（与每日进度、目标天数并列，三者可组合），刷完显示「🎉 已完成全部 36 次」
  - 打卡跨越累计阈值的那一刻自动庆祝（toast + 动画 + 儿童语音，不重复打扰）；撤销打卡正常回退累计数与完成状态
  - 模板支持下发时继承累计目标
- 习惯可选开启**记录耗时**（`trackTime`）：适配写作业、练琴等关注时长的任务；
  - 打卡页交互改为三态：未开始 → **[▶ 开始]**（记录开始时间）；进行中 → **[⏹ 完成]**（打卡得分并结束计时，任务高亮显示「🔴 进行中 · 已开始 N 分钟」）；已完成 → 显示「⏱ 今日 N 分钟」及 [−] 撤销
  - 计时会话按天存入 `timeLogs`，积分日志自动附「（用时 N 分钟）」，完成后可查历史每次耗时
  - 撤销打卡同时删除对应计时会话（退分+清耗时）；级联取消同步清理下游计时会话
  - 与多次打卡、累计目标、目标天数可自由组合；前置任务锁定时 [▶ 开始] 同样被拦截
  - 惩罚任务（负分）不支持耗时记录（编辑器联动禁用）；模板下发继承开关
- 耗时任务可选启用**番茄计时**（`pomodoro`：0 不启用 / 15 / 25 / 45 分钟）：番茄工作法与任务耗时结合；
  - [▶ 开始] 后任务卡实时显示倒计时（🍅 24:31，每秒跳动，局部刷新不重绘），下方显示「🔴 专注中 · 第 N 个番茄」
  - 番茄到点自动响铃提醒（Web Audio 合成叮叮叮，无需外部文件）+ toast「🍅 番茄完成！休息 5 分钟吧」，自动进入休息倒计时（☕ 04:59，45 分钟番茄配 10 分钟休息）
  - 休息结束再次提醒「可以继续啦」；期间随时可点 [⏹ 完成] 提前打卡，或 [🍅 继续] 开始下一个番茄
  - 积分日志记录**纯专注时长**（不含休息）：如「完成习惯：写作业（专注37分钟）」= 1 个完整番茄 25 分钟 + 第二个番茄 12 分钟
  - 倒计时基于时间戳，刷新页面后自动恢复继续；番茄选项随「记录耗时」开关联动显示，负分（惩罚任务）时隐藏
- **独立番茄时钟**（不绑任务的通用专注工具）：底部新增「🍅 番茄」页签；
  - 空闲态：可选 15 / 25 / 45 分钟时长，[▶ 开始专注]；进行中不可改时长
  - 专注中：大倒计时每秒跳动（🍅 24:31），可 [⏹ 提前结束]（专注时长计入统计，不计番茄数）或 [✕ 放弃]（弹窗确认，作废不计）
  - 番茄到点自动响铃提醒并进入休息倒计时（☕ 05:00，45 分钟番茄休 10 分钟）；休息中可 [🍅 跳过休息直接继续]；休息结束提醒回空闲
  - 统计卡：今日番茄数、今日专注时长、历史累计番茄数；今日统计跨天自动重置
  - 切到其他页签倒计时仍持续，到点照常提醒；刷新页面基于时间戳自动恢复；儿童模式大字优化
- **排行榜**（底部「🏆 排行」页签，所有人可看）：家庭全员榜，激发好胜心；
  - 三指标切换：**总积分** / **连续天数**（🔥 N 天）/ **今日完成**（N% 及完成项数），选择持久化
  - 前三名显示 🥇🥈🥉（名次徽章底色金/银/铜，第一名行金色光晕）；同值并列同名次
  - 当前用户行高亮描边并附「我」标记；榜单只读无操作，无需口令
- **艾宾浩斯遗忘曲线复习**（`freq:'ebbinghaus'`）：背古诗、背单词、生字听写等记忆类任务按科学遗忘间隔安排复习——首学后第 1/2/4/7/15/30 天各到期一次，共 7 次，全部完成即「🎉 已记住」；
  - 打卡页仅在学习日/到期日出现：未学习显示「🌱 新记忆 · 今天开始学习」+ [📖 学习打卡]；到期显示「⏰ 今日到期复习（第 N/7 次）」+ [📖 复习打卡]（逾期未复习顺延补卡，同样显示到期形态）
  - 卡片附「🧠 记忆进度 N/7 次」进度条；当日打卡后保留卡片显示「✅ 今日已学习/复习 · 下次 X 天后」并提供 [−] 撤销（回退阶段与积分）；未到期或已记住且当日无打卡时，任务从今日列表隐藏
  - 第 7 次复习完成触发大庆祝（toast + 撒花 + 儿童语音），此后任务不再出现；再次打卡被拦截提示「已完成全部复习」
  - 编辑器选中该频率时联动隐藏执行日期/每日次数/前置任务/目标天数/累计目标/记录耗时（均不适用，保存时强制清空），并显示功能提示；已有任务编辑保留复习进度（不打断阶段），切回普通频率自动清空复习状态
  - 模板支持该频率（列表显示「艾宾浩斯复习（1/2/4/7/15/30天）」），下发后成员从头学习（`ebbStage` 重置为 0）；管理页任务列表显示阶段状态（待学习 / 第 N 次 · 下次 X 天后 / 今日到期复习 / 🎉 已记住）
- 管理员可随时增、删、改任何成员的习惯，调整积分与状态（启用/停用）
- 支持**习惯模板**：预设常见习惯库（学习、生活、运动等），新建成员时可一键套用，按年龄/角色筛选
  - **重复下发拦截**：下发时给任务标记 `templateId`；若成员已有该模板下发的任务或同名任务，下发弹窗中标注「已有此任务」，点击下发会被拦截并提示，不产生重复任务；任务改名后仍能通过 templateId 识别重复
- **前置任务**：习惯可设置前置任务（选填）。设置后，该习惯当天需先完成前置任务打卡才能解锁打卡，适合学习链场景（如 先复习 → 再背诵 → 抄生字 → 做题）；前置任务未完成时，习惯以锁形图标展示并拦截打卡，**点击锁定任务会提示「先完成『××』」**（儿童模式附语音提示）
  - 前置任务仅限同成员习惯，编辑时排除自身，防止自引用
  - 保存时校验循环依赖（如 A→B→A），形成循环时拦截并提示「前置任务不能形成循环」
  - 删除某习惯时，会自动清理其他习惯对它的前置引用
  - **级联取消保护**：取消已打卡任务时，若其他今日已完成任务以它为前置，会弹出确认框（列出受影响任务与总退回积分），确认后一并取消，防止出现「前置未完成但下游已完成」的矛盾数据
- **惩罚任务（负分任务）**：习惯积分可填**负数**（如「不吃零食 -2 分」），即惩罚性任务
  - **语义**：做到（当天打卡）= 不扣分；没做到（当天未打卡）= 自动扣分
  - **扣分上限**：每日结算时扣除 `min(|积分值|, 当前积分)`，积分**扣到 0 为止**，不会变成负数
  - **结算时机**：每日打开页面时自动结算「昨天」未打卡的惩罚任务，积分记录标注「未做到：××」；同日不重复结算（`_punishSettled` 标记）
  - **与前置任务互斥**：惩罚任务不可设置前置任务，也不可被其他任务设为前置；编辑器里负分时自动禁用前置选择并提示
  - 编辑/新增习惯与模板的积分输入框范围调整为 `-20 ~ 10`，负值即为惩罚任务
- **任务创建入口**：「打卡」页不再提供「添加」入口，任务的增、删、改统一在管理设置的「任务管理」中操作，避免孩子误操作

**首版示例成员（两个孩子）的默认习惯建议：**

| 习惯 | 8岁女童（二年级） | 6岁男童（大班） |
|------|------------------|----------------|
| 学习 | 完成作业、阅读、练字、预习 | 认识拼音/数字、听故事 |
| 生活 | 整理书包、收拾书桌、早睡 | 自己刷牙、穿衣、收拾玩具 |
| 运动/健康 | 跳绳、户外活动 | 多喝水、晒太阳 |

### 3.3 打卡与记录
- 成员一键完成打卡，打卡成功有**即时正反馈**（动画 / 音效 / 鼓励语）
- 支持**补卡**：当天忘记打卡可补，但需管理员确认，防止刷分
- 自动计算**连续打卡天数**（连续 / 中断自动记录），形成持续激励
- 每日 / 每周完成情况自动汇总

### 3.4 激励与奖励体系（核心）
- **积分体系**：完成习惯获得积分，按习惯设定值累计
- **奖励兑换**：积分可兑换管理员预设的奖励（实物、游乐时间、零花钱、动画片时间等），提交后由管理员审批发放
- **成就徽章**：连续打卡达到一定天数解锁对应徽章，增强荣誉感和成就感
- 符合儿童心理设计：即时反馈 + 累计目标 + 荣誉激励三层递进

### 3.5 管理端与数据视图
- 管理端聚焦管理功能：奖励审批、成员管理、任务管理（习惯）、任务模板库、数据与存储、安全设置；**今日完成度对比已移除**（与排行榜「今日完成」指标重复，统一在排行榜查看）
- 奖励审批流程（成员申请 → 管理员审批 → 发放 / 驳回）
- 数据本地/私有保存，无需联网到第三方（符合隐私偏好）

### 3.6 任务管理（管理端）
- 管理设置中提供**任务管理**专区，按成员分组展示所有习惯（任务），支持对任意成员增、删、改习惯
- 任务管理中的「编辑」可直接修改成员习惯的名称、图标、积分、频率、执行日期、目标天数、前置任务，「删除」可移除该成员习惯
- 任务列表展示时，含前置任务的习惯会标注「先完成「××」」提示
- 提供**任务模板库**：内置常见习惯模板（学习、生活、运动等），支持新增、编辑、删除模板
- 模板可**下发**给指定成员，下发后该成员习惯列表自动新增该任务（不下发不生效，仅作为模板备选）；
  - **重复下发拦截（双重防线）**：下发时给任务标记 `templateId`；①成员选项防线——已有该模板下发任务或同名任务的成员选项**直接禁选**（标注「已有此任务，不可重复下发」），弹窗默认选中第一个可下发成员；②提交防线——点击下发时若重复则拦截提示，全员已有时提示「无需下发」；任务改名后仍可通过 templateId 识别重复

### 3.7 管理口令安全
- 管理端入口受口令保护，默认口令 `1234`
- 管理员可在「安全设置」中**修改口令**（需输入当前口令验证）
- 忘记口令时，输入默认口令 `1234` 可进入**重置口令**流程：设置新口令后进入管理端，旧口令作废
- 口令解锁**仅对当前会话有效**：解锁状态不持久化，刷新页面后需重新输入口令；刷新后若停留在管理页视图，也会自动回到「我的」主页，防止绕过口令

## 四、差异化设计要求

不同年龄成员识字与认知能力差异明显，界面与交互按成员配置差异化，并以**界面模式**区分：

| 模式 | 适用 | 特点 |
|------|------|------|
| 儿童模式 | 识字有限的低龄儿童（如大班） | 大图标、大按钮、强图形化，图标+语音播报，贴纸/奖杯感 |
| 少年模式 | 已识字儿童（如二年级） | 文字 + 图标结合，文字鼓励语 + 动画 |
| 简洁模式 | 成年人 / 自我管理 | 纯文字紧凑界面，信息密度高 |

**核心原则：** 低龄成员应能在不依赖他人读题的情况下，通过图标和语音独立完成打卡；识字成员可通过文字理解任务；管理端始终提供完整文字信息。每个成员创建时可选择适合自己的界面模式，后续可随时切换。

## 五、非功能需求
- **易用性**：成员端操作极简，一次点击即可完成核心动作
- **安全**：管理端入口需口令保护，防止成员误操作或私自改积分
- **可靠性**：数据不因刷新/换设备丢失，多设备间保持一致；提供**备份导出/导入恢复**，应对浏览器数据被清理、重装系统等意外丢失场景
- **兼容性**：启动时检测浏览器本地存储（localStorage）可用性，隐私模式或禁用存储时降级为内存存储并友好提示，避免功能异常

### v3.4（历史）修复头像全屏查看模糊问题
- **问题原因**：头像上传时压缩至 **128px**（历史设计，为节省 localStorage 空间），全屏查看器把 128px 拉伸到整屏（手机 3~10 倍、桌面约 10 倍），导致严重模糊
- **修复**：压缩尺寸上限从 128px 提升至 **768px**，JPEG 质量从 0.8 提升至 0.85；小图（短边 < 768px）保持原尺寸不放大
- **存储评估**：普通头像照片约 40~80KB/张（极端细节图实测约 150KB），多成员场景总占用远低于 localStorage 限额；手机全屏查看几乎 1:1 清晰，桌面轻微放大可接受
- **注意**：历史已上传头像仍是 128px 低清版，**重新上传一次即可变高清**（旧图无法增强）
- 实测验证：3000px 图压缩为 768px、200×300 小图不放大、上传后全屏查看链路正常，无 JS 报错
